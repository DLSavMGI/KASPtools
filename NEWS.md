# KASPtools 0.1.0

- Initial package version.
- DT96 RDML/XML import with protocol-block selection.
- QuantStudio XLSX import with SNP assay selection.
- Fluorescence kinetics plotting.
- Allelic discrimination with `delta`, `relative_delta`, and `rox` normalization.
- Control-guided empirical clustering and confidence scoring.
- Excel and HTML export.
